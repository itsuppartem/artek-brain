# notes/

Internal development log, in Russian. Each `BRAIN-<n>.md` was written by the AI coding agent that implemented that stage from the specification in [`docs/TZ.md`](../docs/TZ.md): what was done, how to check it, what was left out.
Together they are the history of decisions behind the code (for example, `BRAIN-4.md` adds the task board that was later removed, and `BRAIN-12.md` records the production audit behind 0.2.0).
For the current state in English, see [`docs/`](../docs/architecture.md) and the [changelog](../CHANGELOG.md).
