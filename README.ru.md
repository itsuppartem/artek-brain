# artek-brain

Общая версионируемая память для людей и AI-агентов (Claude Code, opencode), отдельный экземпляр на каждый проект. Внутри нет вызовов нейросетей: чтение и запись детерминированы. Спецификация: [docs/TZ.md](docs/TZ.md). Правила для агентов-разработчиков: [AGENTS.md](AGENTS.md). [English](README.md)

## Что умеет
- **Версии.** Каждая запись — новая версия с автором, причиной, sha256 и diff. Откат документа, версии, правок одного автора за период или пачки.
- **Явные конфликты.** Запись несёт `base_version`; правки разных разделов сливаются, одного раздела — дают конфликт с текущей версией.
- **Права.** Чтение/запись/админ по префиксу пути, токены со сроком и отзывом. Агенты не меняют `rules/`, `owner/`, `approved/`, предложения кладут в `owner/inbox`.
- **Секреты.** Запись с ключом, токеном или PEM отклоняется.
- **Поиск.** SQLite FTS5 (BM25) с фильтрами; если по всем словам пусто — повтор по любому слову по основе.
- **Старение знаний.** Срок свежести по папкам (`settings.json` → `aging.ttl_days`) или `review_by`; бриф и `brain quality report` показывают просроченные документы и «docs отстали от заметок».
- **Бриф и хук.** `brain_op(action="brief")` — короткая выжимка для начала работы. `brain setup` ставит хук Claude Code `SessionStart`: бриф попадает в контекст на старте и после сжатия контекста.
- **Журнал.** Все действия, включая поиски: кто, что, когда, зачем, из какой сессии и какого клиента.
- **Экономное хранение.** Блобы по хешу с дедупом, сжатием и дельтами, квоты, сборка мусора, бэкапы с манифестами.

## Подключить к проекту
```bash
uv tool install --from git+https://github.com/itsuppartem/artek-brain "artek-brain[mcp]"
cd /путь/к/проекту && brain setup --name "Название"
```
`brain setup` создаёт `.brain/` (база и токены `owner.token`, `agent.token`, права 600 на базы и токены, 700 на `blobs/`, в git не попадает), `.mcp.json` для Claude Code и `opencode.json` для opencode (у каждого своя метка `BRAIN_CLIENT` для журнала), блок правил в `AGENTS.md` и хук брифа в `.claude/settings.json`. Повторный запуск безопасен и обновляет блок правил. MCP ищет `.brain` вверх по каталогам, поэтому git-копии агентов внутри проекта пишут в ту же память. Остальные команды без найденного хранилища выдают ошибку, пустой мозг сам не создаётся.

Обновить уже установленный инструмент: `uv tool upgrade artek-brain`, затем `brain setup` в каждом проекте и перезапуск сессий агентов (MCP-сервер стартует вместе с сессией).
